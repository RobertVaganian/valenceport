# Workspace captures

These six images show the running ValencePort prototype with illustrative shipment data. The gallery uses the base assumptions: Suez selected, Cape pinned, a €22,000 budget, 14 December deadline and 40 t emissions limit.

Capture at the native desktop scale after fonts, layout transitions and the route reveal have finished. Keep the pointer and its highlight outside the exported frame, and blur text fields so their caret is absent. Check each final image at full size before reviewing the README gallery.

The workspace and case-study frames are 1353 × 912 px. The comparison uses a 1323 × 912 px frame that retains the complete dialog and footer. No interface region is redrawn or enlarged.

The case study itself renders its map and examples with HTML and SVG. It does not embed these screenshots or a screen-recorded video.
