# ValencePort · Complete project

This folder contains the full editable project: application, case study, fonts, vector geography, route data, tests, source notes and local server. No API key or account is needed to run this copy.

1. Install Node.js 22 or newer if it is not already installed.
2. Extract this ZIP to a normal folder, such as `D:\Portfolio\ValencePort`.
3. Open a terminal in that folder and run `npm run dev`.
4. Open **http://127.0.0.1:8080**. The case study is at **http://127.0.0.1:8080/case-study/**.

No dependency installation is required. Keep the terminal open while using the app. Press Ctrl+C to stop the server. Opening `dist/index.html` directly does not load JavaScript modules correctly; use the local server.

Run `npm run check` to check the project. Read `README.md` for the model, boundaries and architecture. `docs/` contains source and design notes. Font and data licenses are included with their assets.

Settings and saved plans stay in the browser for the local address you use. Download a JSON backup from Saved scenarios before moving to another browser or address. The application uses illustrative planning data and does not book shipments.

The hosted version and this local copy are independent. Editing this folder does not automatically update the hosted site.
